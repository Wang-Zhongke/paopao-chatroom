## 文件

- `holdout.jsonl`：冻结题目和期望检查点；检查点不进入回答请求。
- `context-snapshot.json`：实际拟发送的 Skill、Expression DNA、六份领域 framework 全文。
- `config.json`：固定共享任务、模型、参数、文件哈希、出题哈希和评测协议。
- `answer-Rxx-on/off.json`：完整请求体、响应或连接失败记录；不记录认证头或密钥。
- `blind-package.jsonl`：随机 X/Y 候选包。盲化隐藏臂名，不保证措辞不能暴露人物风格。
- `UNBLIND-KEY.json`：对应关系；独立 Judge 不应读取。
- `run-summary.json`：完成情况、返回模型 ID 和可得用量。

## 同等条件

两臂均使用 `deepseek-flash`、`reasoning_effort=low`、`max_tokens=2200`、非流式请求和相同基础顾问任务、相同用户消息。温度等未显式设置的参数均采用服务默认值，不将其描述成可确定性复现。唯一系统上下文区别是 ON 加载人物资料。每个后续轮次携带自己前一轮的回答，因此多轮对话并不共享回答历史。

每臂最多两轮，两个并发工作线程；连接失败不自动重试。题目、配置及完整输入在请求前冻结。截止输出或空回答标为未完成。模型不提供联网工具；涉及当前事实的题目检查其是否承认未核实。

## 重新运行

在工作区根目录执行（脚本位于外层应用仓库的 `scripts/`，不是轻量 Skill 安装包必需项）：

```sh
python3 scripts/eval_release.py --run --output paopao-perspective-skill/tests/release-v01/authorized-run
```

此命令会付费调用 DeepSeek 并发送 `context-snapshot.json` 所示内容，以及本轮问题与对应对话历史。应在该批内容外发已获得授权、运行环境可联网之后执行。密钥取自 `DEEPSEEK_API_KEY` 环境变量或外层 `.env.local`，永不打印或写入评测记录。

省略 `--run` 只生成冻结输入，不调用 API；该输出目录随后被视为已有评测，正式运行应选另一个新目录。已有 `config.json` 时拒绝覆盖。

成功取得两臂全部回答后，再将盲包单独交给独立 Judge。Judge 应逐题评价决策帮助、上下文更新、行动可执行性、来源纪律、非泛化推理、自然表达，记录偏好/平局与理由。人物声音忠实度需另让熟悉原语料的评审检查，不应以“更犀利”代替“更像本人”。不得把尚未完成的盲评写成成绩。
