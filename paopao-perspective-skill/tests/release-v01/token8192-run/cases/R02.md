## 问题

### 第 1 轮

我们预约服务的页面很好看，但提交率低。老板要我全部重做，你怎么看？

### 第 2 轮

补充：我们查过了，表单到提交的转化其实正常，掉的人主要是在看到预约价格后离开，而且大多不是目标客户。

## Skill ON（盲评标签 X）

### 第 1 轮回答

先说结论：你老板要的不是"重做页面"，他要的是提交率上去。这两件事被他绑成一件了，你得先把它们拆开。

因为"页面好看但提交率低"这句话本身就是个症状，不是病因。好看是属于视觉层的事，提交率是属于决策层的事。用户最后不点提交，绝大多数时候不是因为他觉得不好看，是因为他在最后那一下犹豫了——而犹豫的原因，页面再漂亮也不会自动消失。

所以你别急着接"重做"这个活儿。你先去把这个漏斗拆开看：

打开页面的人有多少、看到表单的有多少、开始填的有多少、填到一半走的有多少、最后点提交的有多少。

这五段流失，对应的病因完全不一样。如果人根本没往下滚，那是首屏没告诉他"这里能约什么、要多少钱、要多久"，是信息问题。如果人开始填了但中途跑掉，十有八九是表单太重——字段太多、非要手机号验证、非要登录、时间选项点不开、价格要填完才知道。如果人填完了但没提交，那可能是信任问题：没有确认凭证、没有客服入口、不知道提交完会发生什么、怕被推销。还有一种特别常见的，是他压根没搞明白这服务是给谁做的，来了发现"不是我要的"，那这是流量和定位的问题，重做一百遍页面也没用。

你看，这里头有几条是"重做视觉"能解决的？基本没有。重做视觉能解决的是"用户根本不相信你"，而这个也得靠文案、案例、真实评价、明确的价格和退改规则去解，不是靠配色和留白。

老板为什么会说"全部重做"？因为那是他手里唯一能立刻下的指令。他不知道漏在哪一层，重做是他能想象的最大的动作。你要做的不是听话去重做，也不是硬顶他，而是把这个问题变成能看得见的东西：把漏斗数据摆出来，告诉他漏在哪一格，然后在那一格上做实验。

具体怎么干，你先别动设计文件。找五到十个真到了页面但没提交成功的人——老客户、被邀约没来的、客服那边有记录的——直接问一句"你当时为什么没约成"。你问五个人左右，答案会开始重复，那个重复的答案就是真病因。同时导一段会话录屏，看他们卡在哪一步、鼠标在哪停、在哪返回。

然后你就有一个能跟老板讲的版本了：不是重做，是"这一格在漏，先改这一格"。这也比"全部重做"便宜得多、快得多，而且改完能立刻看数据。

顺便说一句，"页面很好看"这件事本身也值得怀疑。好看是你们自己觉得好看，还是用户觉得好懂？预约页的美感标准不是赏心悦目，是"我一眼知道我要做什么、做什么代价、点了之后会发生什么"。一个让人觉得清楚、能信任、敢下手的页面，才是这个场景里的好看。

所以你现在先干什么——别改设计，先去拿漏斗数据和五个人的一手反馈。拿到之后你再来找我，我们看是该动视觉还是该动结构。

### 第 2 轮回答

好，现在这个信息就把问题彻底翻过来了。你老板要重做页面这件事，基本可以判定是在错的层上动手。

先盯住你刚说的两件事：看到价格后离开，而且大多不是目标客户。

这两件放一起,结论就有了——**这批人离开不是损失,是筛掉。** 他们本来就不会成交,他们是价格不匹配的人群,他们走了页面反而更干净。你为了把这些人留住去重做页面,等于花力气去挽留根本不该来的人。这不是优化转化,这是把转化率做假。

那老板说"全部重做"在解决什么?什么都没解决。因为非目标客户离开,根本不是页面好看不好看的问题,是他本来就不是客户。你页面做得再美,一个预算差三倍的人也不会突然买单。

所以你真正要分清的,是两个完全不同的问题,你老板把它们糊成一个了:

**第一个问题:来的人是不是对的人。** 非目标客户占比这么高,说明流量入口有问题——投放的渠道、关键词、合作方,把一堆不匹配的人引进来了。这是投放和定位的活儿,重做预约页一点用没有。

**第二个问题:对的人来了之后,价格这一步他走不走。** 这才是页面能碰的部分,而且要碰的往往不是"好不好看",是**价格出现的时机和方式**。

这里有个特别常见的坑:很多预约流程把价格藏在填完表之后。用户填了姓名、手机、需求、时间,最后一步才蹦出价格,他会觉得被套路了,投入了时间成本还被"关在里面",这时候走的概率特别高。你先确认一下你们是不是这样。

如果是,那解法很可能是反直觉的:**把价格往前放,放到首屏或者流程第一步。** 会怎样?非目标客户一看价格就自己走了,根本不填表;能接受价格的人进来,填完就提交。你的总提交量可能看着没大涨,甚至绝对数下降,但那是好事——来的人对了,成交和后续跟进成本都会降。你不能用"总提交数"这个指标骗自己。

那页面到底要不要动?要,但动的是这个:
- 价格有没有提前、清楚地告诉用户;
- 价格旁边有没有给足锚点(包含什么、对比什么、为什么值);
- 用户看完价格,下一步的按钮和理由够不够;
- 有没有一句明确说"这是给谁做的",把非目标客户礼貌地劝退。

这些是信息结构和信任的活儿,不是配色和留白。

现在最关键的一个数字你得先拿到:**目标客户看到价格之后的转化率是多少?** 如果目标客户在价格这步走掉的比例其实很低,那就证明流失的是非目标客户,你老板要重做的这件事完全没必要,你该去查流量来源。如果目标客户也大量在这走,那才轮到动价格本身或价格的呈现。

另外提醒一句,"大多不是目标客户"这个判断是怎么得出来的,你自己先核一下——是客服事后标的,还是根据没二次接触推的?这个判断要是站不住,后面全错。

所以你现在别碰设计稿,去干两件事:一是把提交数据按渠道拆开,看非目标客户从哪个入口进来的;二是把目标客户在价格这步的转化单独拉出来。这两个数一出来,你和老板的对话就从"要不要重做"变成"漏点到底在前端还是在这",那就有的聊了。

## Baseline OFF（盲评标签 Y）

### 第 1 轮回答

**我的判断：先别“全部重做”。**  
页面好看和提交率高是两件事。提交率低，通常不是审美问题，而是**动机、信任、摩擦、时机、流量质量**的问题。全量重做成本高、周期长，而且很可能治错病——最后页面更漂亮，提交率还是不动。

### 先拆漏斗，不要先动设计
你需要把“提交率低”拆清楚：

访问页面 → 点击预约 → 开始填写 → 填到一半 → 点击提交 → 提交成功

哪个环节掉得最狠，原因完全不同：

- **访问多但点击少**：首屏价值主张不清、CTA弱、用户不信任、流量不精准。
- **点击多但开始填写少**：表单看起来很麻烦、需要登录、不知道要填多久。
- **开始填写但没提交**：字段太多、日期难选、没有可用时段、验证码烦、移动端难用。
- **提交了但没成功**：技术错误、提交失败无提示、等待确认太久。
- **提交成功但老板认为低**：指标定义错了，可能要看“有效预约”而不是“点击提交”。

### 最该先看的几件事
1. **分来源看**：广告、搜索、私域、老客推荐来的提交率完全不同。流量不精准，重做页面也没用。
2. **分设备看**：移动端占比高的话，90%问题可能在移动端体验。
3. **看录屏和热图**：用户在哪犹豫、反复点哪、放弃在哪。
4. **访谈5-10个流失用户**：问“你当时为什么没预约完？”比内部猜有效得多。
5. **检查表单字段**：每多一个非必要字段，都会掉转化。电话、邮箱、公司、需求描述，能后补就后补。
6. **检查预约后承诺**：用户点提交后会发生什么？多久确认？能不能改期？不透明会让人不敢提交。

### 优先做低成本实验，而不是全量重做
按杠杆从高到低：

1. **首屏改清楚**：一句话说清“提供什么、给谁、为什么现在预约”。
2. **减少字段/分步填写**：先留姓名+联系方式+时间，其他后补。
3. **直接显示可预约时段**：不要提交后等人工联系。
4. **把信任元素放到CTA旁边**：资质、评价、服务人数、隐私承诺、退款/改期政策。
5. **移动端优化**：大按钮、固定CTA、正确键盘类型、自动填充、错误提示。
6. **提交按钮文案具体化**：比如“确认预约”而不是“提交”。
7. **做A/B测试**：一次改1-2个变量，看开始填写率、完成率、提交成功率。

### 什么情况下才值得重做？
如果出现这些，才考虑整体重做或关键路径重构：

- 技术架构严重限制，表单无法改、埋点加不了、移动端根本不可用；
- 品牌和定位已经变了，页面与业务不匹配；
- 多个实验都无效，且用户访谈一致指向结构性问题；
- 流量成本很高，现有页面长期拖累ROI，重做收益能算清楚。

但即便如此，也建议**分模块重做**：首屏、表单、信任区、确认页，而不是整站推倒。

### 跟老板可以这样说
“我同意要提升提交率，也支持必要重做。但全量重做前，建议先用1周做漏斗诊断和2-3个高杠杆实验。如果实验证明瓶颈在页面结构，我们再立项重做，风险更低，也能拿数据说话。”

### 要给你更具体的优先级，我还需要知道
1. 提交率具体是哪个环节到哪个环节？
2. 流量主要来自哪里？
3. 移动端占比多少？
4. 表单有几个字段、几步？
5. 有没有埋点、热图、录屏或客服反馈？

一句话：**老板要的是提交率，不是新页面。先找漏点，再决定重做哪里。**

### 第 2 轮回答

这个补充很关键，**基本可以推翻“页面要全部重做”的判断**。你现在描述的不是转化问题，而是**筛选问题**——价格正在帮你挡掉非目标客户。这未必是坏事，甚至可能是健康的。

### 先修正判断
之前我说要拆漏斗。现在漏斗拆出来了：

- 表单到提交：正常
- 掉点在“看到价格之后”
- 掉的人大多不是目标客户

那么真正的问题不是“页面让人不想提交”，而是：

**非目标客户被吸引到了预约页，看到价格后自然离开。**

这有两种可能，性质完全不同：

1. **好事**：价格在正确的位置完成了筛选，省了销售和客服的时间。
2. **坏事**：目标客户也在看到价格后离开，或者价格呈现方式让目标客户犹豫。

你说“大多不是目标客户”，但**“大多”不等于“全部”**。必须确认：目标客户看到价格后的行为是什么？如果目标客户也掉，那才是真问题。

### 老板要的“提交率”可能是个错误指标
如果提交率的分母里混进了大量非目标客户，那这个指标本身就有问题。真正该看的是：

- **目标客户的提交率**
- **有效预约率**（提交后实际到场/成单）
- **单条有效预约的获客成本**
- **销售/客服在非目标客户上的时间浪费**

提交率下降，但有效预约率上升，这可能是优化，不是退步。跟老板必须把这个问题说清楚。

### 真正该动的地方大概率不在这页
按杠杆排序：

**1. 上游流量和预期管理**
非目标客户为什么会进来？大概率是：
- 投放素材/关键词太宽，吸引来价格敏感或需求不匹配的人；
- 落地页首屏没提价格区间或服务定位，用户抱着错误预期点进预约；
- SEO/内容吸引来的是“随便看看”的人。

解法：在**到达预约页之前**就传递价格区间或定位。比如落地页首屏写“XX服务，起价XX”，或者投放定向收窄。**让不合适的人在更早的地方离开，比在预约页离开更省钱。**

**2. 价格呈现的时机和框架**
价格不该藏到预约最后一步才出现，那会制造被“套路”的感觉。但也不该在首屏就冷冰冰甩一个数字。可以考虑：
- 在预约前用“价格区间 + 价值锚点”说明，比如“含XX服务的预约，XX起”；
- 把价格和“包含什么、省了什么、对比什么”放在一起；
- 提供不同档位，让用户有参照，而不是单一数字的冲击。

**3. 预约页本身的微调，而非重做**
- 在预约CTA附近就给出价格预期，避免走到最后才被“价格突袭”；
- 对非目标客户，提供“不适合”的出口（比如更便宜的自助方案、常见问题），减少无意义提交；
- 对目标客户，强化信任和稀缺性，而不是靠页面美观。

### 需要确认的关键未知
1. **目标客户看到价格后，提交率是多少？** 如果也低，问题在定价或价值传达；如果不低，那就是流量筛选问题。
2. **“不是目标客户”的判断依据是什么？** 是预算不符、需求不符，还是地域/资质不符？
3. **价格出现在预约流程的哪一步？** 是首屏、中途，还是提交前？
4. **流量来源结构**：哪类渠道带来的非目标客户最多？
5. **有效预约率/到场率/成单率**近期有没有变化？

### 跟老板可以这样说
“数据指向的不是页面体验问题，而是流量质量和预期管理问题。表单本身没问题，价格在筛掉非目标客户。全部重做大概率不会提升有效提交。我建议先确认目标客户在看到价格后的行为，同时优化上游投放和价格呈现时机。如果目标客户也在掉，我们再针对那部分改预约页。”

一句话：**你现在缺的不是更好看的页面，而是更准的流量和更早的价格预期。** 老板要提交率，你要的是有效预约率。
