# 研究资料与公开包

| 层 | 内容 | 适合谁 |
|---|---|---|
| 使用层 | Skill、框架、表达 DNA、示例 | 想直接使用的人 |
| 追溯层 | 来源地图、逐视频研究卡、时间演化、研究摘要 | 想核对模型依据的人 |
| 本地研究层 | 完整机器字幕、逐帧 OCR、原始响应和缓存 | 维护者复核与研究 |

轻量发布包包含前两层。第三层继续留在本地，不随公开包分发。353 条、约 121.9 小时描述的是研究覆盖范围，而不是压缩包提供的完整音视频或转录规模。

## 如何核对一句判断

1. 在 [心智模型](../references/mental-models.md) 找到对应模型。
2. 打开 [来源地图](../references/source-map.md) 和相关视频研究卡。
3. 根据视频日期、BVID、时间定位回看原视频。
4. 区分人物原话、研究者归纳与当前模型推演。

机器文本可能误识别人名、数字、反讽或画中素材。重要逐字引用应回看原视频；缺少证据时请提交疑问，不补写不存在的原话。

## 完整资料如何获得

本项目不提供未确认分发权限的完整字幕下载。可以通过来源链接自行观看，或在具备相应权限的情况下使用维护者采集脚本研究。采集脚本不是运行 Skill 的前提；平台登录、接口、字幕可用性可能随时间变化。

本地 corpus-index 是采集状态源。公开包会净化索引，只保留公开标识、日期、质量和应用运行所需字段；不会附带临时字幕地址或完整 API 响应。

## 连麦室与资料的关系

连麦室加载 Skill、相关框架和来源卡片。完整本地研究环境还会读取可检索转录片段；公开源码包没有完整字幕，使用研究卡与原视频链接，二者检索上下文不同。不能把仅研究卡的公开版宣传为已加载 121.9 小时全文。
