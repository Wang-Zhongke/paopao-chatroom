# 泡泡老师视角 · Paopao Perspective

用泡泡老师的思考方式，拆解你的职业选择、AI 转型和商业困惑。

基于像素范 / 水球泡公开内容整理的非官方人物 Skill。加载后，用直接、口语化的表达追问真实需求、岗位责任和可带走的能力。

**[安装使用](docs/INSTALL.md) · [真实回答](tests/persona-ab-v1/run/CASE-INDEX.md) · [人物模拟评测](tests/persona-ab-v1/run/EVAL-REPORT.md) · [研究与来源](docs/RESEARCH.md)**

## 先看一次回答

**问题：** 35 岁，有房贷和孩子，在大公司做内部报表。一家 AI 创业公司降薪 20%，承诺负责核心产品，值得去吗？

> 我现在偏向你先别去。不是因为你 35 岁、有孩子就不能冒险，而是你拿一个确定的损失——降薪 20%——去换一句还没兑现的话：“负责核心产品。”这四个字现在不是机会，是一张欠条。
>
> ……你不是在选大厂还是创业公司，你是在判断这次降薪到底买到了能力，还是只买到了风险。

摘自已有测试的模型回答，中间省略了对权限、资源、客户和家庭现金流的追问。**这是 AI 生成示例，不是泡泡老师原话。** [查看完整回答](tests/voice-v2-results.md)。

## 适合拿它来问什么

| 场景 | 可以直接复制的问题 |
|---|---|
| 工作与 Offer | 用泡泡老师的视角分析这份工作：日常任务是……，薪资是……，我更看重…… |
| AI 转型与学习 | 我做了三年数据分析，想转 AI 产品。按泡泡老师的思路，先检查我缺什么证据。 |
| 产品、内容与生意 | 我想为……做一个……产品。按泡泡老师的思路拆解谁会付钱、先验证什么。 |

也覆盖作品集、设计与产品取舍、个人品牌、团队管理。是否能查新事实，取决于宿主工具是否提供联网能力。

## 开始使用

下载并解压轻量 Skill 包后，在含有 SKILL.md 的文件夹内运行：

```sh
python3 scripts/install.py
```

安装器默认复制到个人 `.agents/skills` 目录，不覆盖已有同名 Skill。在 Codex CLI / IDE 中输入：

```text
使用 $paopao-perspective-skill，分析这份工作值不值得去。
我的背景是……，岗位日常是……，我最在意的是……
```

不需要先安装 Nuwa，也不需要运行字幕采集脚本。Skill 本身不需要 DeepSeek 密钥；模型由宿主工具提供。连麦室应用才使用 DeepSeek API。手动安装、旧版本目录及首次验证见 [安装指南](docs/INSTALL.md)。

## 它怎样思考

| 核心模型 | 放到你的问题里，就是问…… |
|---|---|
| 问题高于工具 | 你学的东西要解决谁的什么问题？ |
| 需求侧定价 | 谁需要这个结果，为什么愿意为它付钱？ |
| 行动与反馈 | 做什么小产出，能让现实告诉你方向对不对？ |
| 组织与产业位置 | 这个岗位每天做什么，有什么责任和资源？ |
| 可携带手牌 | 离开现在的公司，你还能拿出什么？ |
| 专业、分发与信任 | 你有什么价值，谁能看见，为什么会再次选择你？ |

详细论据见 [心智模型](references/mental-models.md)。表达包括判断顺序、反问、职业案例与个人—行业—行动之间的切换，见 [Expression DNA](references/expression-dna.md)。

## 证据与当前状态

研究清单覆盖 353 条官方「泡言泡语」视频，约 121.9 小时，另有早期设计教学、访谈和文章。353 是本地机器文本的覆盖数量，**不表示全部经过人工逐字核验，也不表示下载包包含完整字幕**。细分背调、谈薪和内部管理实践仍有语料缺口。

当前作为实验性 v0.1 候选分享。最新测试让两组都模拟泡泡老师，仅一组加载Skill，按原始字幕评人物还原：两名独立Judge分别在10/12和12/12题偏好Skill，四维均分ON 3.46/5、OFF 2.66/5；两题意见分歧，一些具体观点仍还原不足。详见 [人物模拟评测与完整案例](tests/persona-ab-v1/run/EVAL-REPORT.md)。这是小样本增益证据，不是本人认证或高保真已验证。

此前用普通顾问作为baseline的12题评测得到ON 0/12、六维均分2.806对3.792；[旧报告](tests/release-v01/token8192-run/EVAL-REPORT.md)保留作为通用建议质量参考，不应替代人物忠实度评测。两轮题目、指令和标准不同，分数不可直接比较。历史三题声音测试仅作样例。

文件与链接可用标准库 Python 自检：

```sh
python3 scripts/validate_skill_content.py
```
