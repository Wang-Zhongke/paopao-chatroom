# Personal Brand Framework

## 1. 定位

个人品牌不是“包装自己”，而是让专业价值在组织外可见、可理解、可调用，并沉淀信任与分发。它是职业第二资产/期权，不是保证变现的主业替代品。

## 2. 什么时候开始

满足以下任一条件即可小规模开始：

- 正在解决一类真实问题，有可复盘过程；
- 正在转型，需要用公开项目测试市场反馈；
- 专业能力已有，但离开公司后几乎无人知道；
- 所在行业获客、招聘或合作越来越依赖公开可信度。

不需要“准备好”再开始；现金流脆弱时先保留主营收入，用一轮低成本发布观察有没有真实反馈。

## 3. 三个乘数

`个人品牌资产 ≈ 可验证专业价值 × 持续分发 × 信任`

- **专业价值**：具体帮助谁解决什么问题，有案例与边界。
- **持续分发**：稳定触达而非等待单条爆款。
- **信任**：诚实归因、不过度承诺、长期一致、允许被验证。

任何一项接近零，结果都会很弱。流量扩大价值，也会扩大空洞与错误。

## 4. 内容从哪里来

- 真实项目中的选择、失败、复盘；
- 用户/候选人反复提出的问题；
- 行业版本变化与旧建议为何失效；
- 工具如何接到业务结果，而非教程搬运；
- 对一个具体案例按需求、价值链和组织结构拆解。

避免纯观点囤积。每条内容尽量有场景、证据、限制和下一步。

## 5. 黑箱试验协议

1. 定义一个窄人群和一个问题；
2. 选择一种可持续格式；
3. 连续发布一批小样本，不等单条内容完美；
4. 观察有效反馈：目标用户私信、收藏后行动、咨询、合作、付费，而不只看播放；
5. 保留有效问题与表达，停止无反馈方向；
6. 每轮只改一个变量（选题、开场、案例或 CTA）；
7. 持续没有目标信号时，重做定位或暂停。

## 6. 流量、商业化与个人 IP

- 流量是触达和获客基础设施，不是最终产品；
- 商业化必须回到具体付费问题、交付成本和复购/口碑；
- IP 是信任和预期的压缩，不是人设戏剧；
- 专业深度提供可交付价值，影响力降低被发现和交易成本；
- 平台流量不是自有资产，应沉淀可携带作品、名单、社群、客户关系和品牌搜索。

## 7. 风险与边界

- 不辞职追逐未验证流量；
- 不制造焦虑、虚假收入、伪造案例或课程结果；
- 不把私人生活过度暴露当增长义务；
- 不用 AI 批量制造低质量内容；工具抹平制作门槛后，问题、内容和信任更关键；
- 不把“被喜欢”当专业、事实和伦理的替代物。

## 8. 输出判断

回答“我该不该做自媒体”时，顺着问题自然检查：

1. 职业防御价值；
2. 学习/反馈价值；
3. 获客/商业价值；
4. 时间与现金流成本；
5. 可持续题材和证据来源；
6. 低成本验证与停止条件。
