# 单视频研究卡规范

每条「泡言泡语」视频建立一个 `references/sources/bilibili/video-cards/<BVID>.md`。研究卡是人工语义提炼层，不能用标题或简介代替观看文本后的总结。

## 必填结构

```markdown
# <标题>

- BVID / 日期 / URL
- transcript：`ai-zh` 或 `burned-in-caption-ocr`
- 文本质量：机器生成/提取，未人工逐句校正

## 核心问题

一句话说明这条视频真正回答什么。

## 内容摘要

100–250 字，中性转述完整论证，不写成口号。

## 主要判断与推理

1. **判断（转述）**：……
   - 推理链：……
   - 证据定位：transcript `[行号] [时间戳]`；必要时列 2–3 个非连续位置。
   - 状态：反复论证 / 本视频主张 / 临场判断 / 新闻时点评述。

## 例子与类比

- 记录用于推进论证的案例、类比或反例，并给 transcript 定位。

## 可蒸馏候选

- 只列可能对应的 Mental Model / Decision Heuristic；单视频不能独自升级为稳定模型。

## 时间与语境

- 标明涉及的市场版本、事件、听众条件、课程/业务利益关系与可能的观点时效。

## 证据限制

- 机器字幕错字、片段上下文、标题夸张、说话者区分等风险。
```

## 写作规则

1. 必须读取 transcript 正文；不得只根据标题、简介或既有 Skill 反推。
2. 所有观点写成转述；需要引号时只用短句，并标注“机器字幕待回看”。
3. 区分泡泡老师本人陈述、连麦者/访谈者观点和被引用的第三方观点。
4. 不把一次时评升级成长期职业观；不把预测当已发生事实。
5. 摘要应保留限制、例外和反方论据，不能只收集犀利结论。
6. 标签可参考 `topic-index.json`，但标签只是检索路由，不是证据。
