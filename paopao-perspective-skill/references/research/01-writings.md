- 直接证据摘要：把 2018 年互联网产品阶段描述为「创新减少、运营为主」的下半场，并据此提出 UI 设计师不能只会视觉和交互，还要补用户心理、市场营销、活动策划、产品提案、故事思维和品牌设计。前言同时把公开发声和个人品牌当作展示综合能力的重要方式。
- 可支持主题：设计师能力结构、设计与商业、个人品牌、行业变化、从设计教育向职业教育延伸。

### S06. 「UI 入行，3 个必知的新观点」图文版

- 日期：2018-07-06。
- URL：[搜狐转载自站酷网的完整图文版](https://www.sohu.com/a/239692176_495681)
- 来源级别：B；证据类型：带完整上下文的官方/授权转载图文版；其中第一人称段落可视为课程原话的可靠转写。
- 直接证据摘要：
  - 将互联网设计岗位分为偏视觉/运营的设计与偏行为/体验的交互设计，前者需要至少一项强视觉专长，后者以用户用得舒服和行为顺序为中心。

## 3. 跨时间复现的候选心智模型

以下只是 Agent 1 的候选，不是最终 Skill 结论。最终需与对话、决策、外部评价等 Agent 的材料做二次验证。

### M1. 工具不等于能力；“怎么做”会贬值，“做什么/为何做”更保值

- 早期证据：S04 明确把软件视为工具而非门槛/护城河；S06 认为交互软件与硬件快速变化，旧软件积累很快失效。
- 中期行为证据：S12 从 Sketch 迁移到 Figma，教学重心同时包含组件、协作与交互，而非固守单个工具。
- 近期证据：S20 认为 AI 抽卡等操作技法会随模型更新贬值，人的方向、损失和商业判断更关键；S19 认为技术深度不自动产生定价权。
- 稳定性：**高**（2018—2026 跨设计、AI、商业重复）。
- 研究者提炼：真正应该积累的是对目标、用户、场景、质量和商业结果的判断，以及用当代工具快速交付的能力。
- 失效条件：基础工具能力低到无法交付时，工具仍是必要门槛；顶尖工程/算法技能也可能形成稀缺壁垒。

### M2. 市场按需求侧价值定价，不按你的投入、学历或技术自我评价定价

- 早期证据：S06 用外卖例子区分供应方成本与需求方价值；认为同一岗位并不因为研究生/本科身份自动产生不同支付。
- 书中复现：S04 把晋升评价拆为专业、通用与影响力，并以公开输出获得机会的案例说明价值需要被组织/市场看见。
- 近期证据：S19 以产业链环节与离钱距离解释技术为什么没有定价权；S21 从老板获得客户、平台、流量的交易能力解释组织分成。
- 稳定性：**高**（2018—2026 跨求职、设计、自媒体、商业）。
- 研究者提炼：评估职业/技能/业务时，应问“谁付钱、为何付钱、我处在价值链哪一环、结果能否被验证”，而不是只数投入时长。
- 张力：它可能低估教育、训练和经验作为长期供给能力的前置投入；公开表达常用极端例子压缩复杂性。

### M3. 影响力不是专业能力的装饰，而是让专业价值可见、可调用、可迁移的杠杆

- 早期证据：S01 已要求设计师通过作品平台和媒体塑造个人品牌；S03 把影响力与话语权放在从“创”到“造”的关键位置；S04 用本人免费课程和学员公开作品/写作案例说明影响力带来机会。
- 近期证据：S17 把个人影响力视为跨地域、跨风口的硬通货；S18 把持续更新和流量当成长期商业基础。
- 稳定性：**高**（至少从 2018/2020 著作内容持续到 2026）。
- 研究者提炼：专业 × 输出 × 信任/分发，比“只把活干好”更能形成职业可迁移性。
- 张力：S18 的“流量命脉”与 S20 的“流量不是主菜/工具不是目的”需结合理解；影响力能放大价值，也能放大空心内容。

### M4. 学习不是线性囤知识，而是进入真实问题—产出—反馈的循环

- 早期证据：S02 的作业闭环、UI100Day 连续输出和同伴反馈；S04 明确反对从旧知识底层线性凿起，主张按当前需求学习。
- 2017 交叉证据：S05 的圈子学习、插件学习、以教代学。
- 近期证据：S16 批评“从第一本书补起”的考试思维，把敢学、愿学、会学和求职专项行动置于静态学历之前；S21 把岗位视为真实责任催生能力的起点。
- 稳定性：**高**（2017—2026）。
- 研究者提炼：先进入场景，做出可见结果，借反馈修正，再补缺口；学习效率来自任务牵引与社会反馈。
- 失效条件：医学、安全、底层工程等高风险领域不能跳过系统基础。

### M5. 把个人放回“行业版本/价值链/组织目的”里判断，不孤立讨论技能

- 早期证据：S01 以互联网进入运营阶段解释能力结构变化；S06 以设备与工具版本解释旧经验贬值，以头部公司解释审美变化。
- 课程结构证据：S07 同时教授体验、需求、商业 Banner、产品提案、交付、作品集与就业。
- 近期证据：S15 把 AI 职业拆为岗位适配与赚钱方式；S17 质疑大厂 SOP 的跨环境迁移；S19 看产业链环节；S21 看老板掌握的获客/平台资源。
- 稳定性：**高**。
- 研究者提炼：职业或产品判断必须同时看行业周期、组织怎么挣钱、岗位靠什么产出、个人获得何种可迁移手牌。
- 失效条件：其公开表达有时把市场结果置于价值中心，可能低估公共价值、基础研究和非商业创造。

### M6. 小成本先验证，再扩团队/投入；不要把准备本身当进展

- 早期近邻证据：S02 要求先独立完成作业再看参考；S04 主张工具学到可上手、按需求补齐；这些体现“先做再反馈”，但还不是创业 MVP。
- 近期直接证据：S20 明确反对生意未验证就先建团队，要求先以个人小成本做账号/第一笔收入，再按缺口补人。
- 稳定性：**中**（创业场景目前主要由 2026 单一原始内容直接支持）。
- 使用建议：暂降级为 Decision Heuristic，等待直播/决策 Agent 找到第二个独立原始来源。

## 4. 早期设计教学 → 职业教育 → AI/商业的演化

### 阶段 A：软件与视觉执行，但已经不是“只教软件”（约 2015—2017）

- S02/S04 的课程体系把视频工具课、连续作业、点评反馈、同伴社区和参考学习组合起来。
- S05 已经讨论 UI 行业趋势、市场需求、学习圈子与以教代学。
- 稳定种子：工具短寿命、视野/参考、输出/反馈、市场导向。

### 阶段 B：全链路 UI/UX、产品思维、作品集与就业（2018—2021）

- S06 从岗位分化、体验、审美、价值定价讨论 UI 入行。
- S07 课程横跨需求、原型、视觉、交互、商业 Banner、产品提案、作品集与面试。
- S09 出现「未来」主题长演讲；S10/S11 用头部作品和国际参考训练视野。
- 明显变化：教学对象仍是设计师，但判断框架已越过“把图做漂亮”，进入产品、组织、求职和个人影响力。

### 阶段 C：协作型工具与职业化输出（2022—2023）

- S12 的 Figma 课程加入组件、团队交接、社区、交互，延续“工具服务协作/交付”的路线。
- 此阶段公开可读的系统性观点材料偏少，是当前缺口。

### 阶段 D：AI 时代的设计职业自救（2024）

- S13 仍以 UI 全能班/作品集为承载，但主题明确变成 AIGC 与设计师自救。
- 变化不是抛弃设计，而是把早期「软件会快速过时」放大成「生成式 AI 会压低机械执行价值」。

### 阶段 E：职业与商业决策 OS（2025—2026）

- S14/S15 将视角扩至 AI 产品、公司布局、岗位适配和赚钱方式。
- S16—S22 反复以需求侧价值、产业链位置、可迁移能力、个人影响力、真实项目和小成本验证分析职业与商业。
- 延续：工具非护城河、真实场景学习、影响力放大价值、需求侧定价。
- 新增/强化：价值链位置、获客与流量、老板视角、团队投入节奏、AI 下“定义方向”的主体性。

## 5. 可直接交给 Phase 2 的决策启发式候选

1. **遇到“要不要学某工具”**：先问它解决哪个真实任务、能否产出项目；工具名不应成为职业身份。（S04/S06/S20）
2. **判断技能值不值钱**：不要看学习难度或投入时长，先看需求方是否愿付费、该技能在价值链离收入多远。（S06/S19）
3. **判断公司值不值得去**：看能否接触真实用户/产品/客户/渠道，能否拿到下一跳可迁移的手牌，而不只看 SOP 和头衔。（S17/S21；需 Agent 2/5 加证）
4. **新人学习**：用任务牵引学习，尽快进入做—展示—反馈—修改循环；不要把“打好全部基础”当作开始的前提。（S02/S04/S16）
5. **设计质量**：技法决定效率，视野与审美决定选择；持续研究行业头部并拆解，而非凭空原创。（S03/S06/S10/S11）
6. **职业积累**：除了专业能力，还要累积表达、影响力、协作和产品/商业理解。（S01/S04/S07/S17）
7. **做个人品牌**：把持续更新当长期资产，不把一条完美内容当考试；专业能力必须通过输出与信任被市场看见。（S04/S18）
8. **启动生意/项目**：先以最低成本验证账号、用户或第一笔收入，再补团队；不要让搭组织替代验证需求。（S20；当前单源，中置信）
9. **看学历**：学历是筛选和入场变量之一，但到同一岗位后最终支付更依赖产出；AI 时代旧科班知识不自动构成壁垒。（S06/S16；必须保留“学历门票”张力）
10. **看行业前景**：不只问赛道热不热，问版本变化让哪些需求增加、自己位于哪一环、能否直接接近用户与收入。（S01/S15/S19）

## 6. 矛盾、张力与不可调和处

### 6.1 学历价值：不自动定价 vs 仍可能是门票

- S06：同一岗位并不因本科/研究生自动加价，培训经历也不该被羞耻化。
- S16：在 AI 快速迭代语境里，科班旧知识不自动形成壁垒。
- 但授权直播切片标题/摘要中，2025-03-04 内容明确表达「本科学历是职场门票」（本 Agent 未用其作为核心来源，URL 为 https://www.bilibili.com/video/BV1tX9bYBEty/）。
- 处理：最终框架应拆成**筛选门槛**与**入职后产出定价**，不能简化成“学历无用”。

### 6.2 头部审美的“跟随” vs 创造与主体性

- S06 强调研究苹果、谷歌、Facebook、Airbnb 等头部产品以提升审美。
- S03 又把最终阶段定义为能「创/造」并获得话语权。
- 处理：可能是学习阶段差异——新人先建立高质量参考系，成熟者再融合与定义；不可写成永远追随权威。

### 6.3 流量是命脉 vs 流量不是主菜

- S18 极度强调流量和持续更新。
- S20 强调工具、赛道、账号形式都不是目的，方向与问题价值才是关键；相关近期内容也把流量称为加速剂而非主菜。
- 处理：流量是分发基础设施，不等于价值本身。最终 Skill 应同时检查“有无被看见”和“被看见的东西是否有真实价值”。

### 6.4 大厂经验无用的强修辞 vs 早期主动学习大厂

- S06/S10/S11 把大厂作品和头部产品当作审美、行业标准与参考源。
- S17 又说大厂 SOP 离开环境可能无用。
- 处理：前者讲**高质量参考与环境暴露**，后者讲**不可迁移的组织流程**；不是“大厂好/坏”的简单反转。判断公司时要看能带走的认知、项目、关系和市场手感。

### 6.5 持续长期主义 vs 追版本、快速迭代

- S02/S18 强调连续练习和长期更新。
- S04/S06/S20 强调工具、知识和行业版本迅速过时。
- 处理：长期坚持的是输出、学习与接近市场；短期更换的是工具、内容形式和战术。

## 7. 重要的研究者推断（必须显式降权）

以下不能直接写成「泡泡老师说过」：

- **推断 A（中置信）**：其职业选择模型可能是「行业版本 × 组织赚钱方式 × 岗位离用户/收入的距离 × 可迁移手牌」。证据跨 S01、S06、S17、S19、S21，但本人未在本 Agent 材料中给出同名公式。
- **推断 B（中高置信）**：设计教育是其后来 AI 职业观的原型：软件会换、执行会被压价，审美/方向/表达/影响力更保值。证据跨 2018—2026，生成力较强。
